# Rock Paper Scissors Game

A browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## Features

- Rock, Paper, and Scissors gameplay
- Computer generates random moves
- Win, loss, and tie score tracking
- Score is saved using Local Storage
- Reset Score functionality
- Auto Play mode
- Keyboard controls:
  - `R` → Rock
  - `P` → Paper
  - `S` → Scissors

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run

1. Clone the repository.
2. Open `12-rockpaperscissors-2.html` in a web browser.
3. Choose Rock, Paper, or Scissors to start playing.
